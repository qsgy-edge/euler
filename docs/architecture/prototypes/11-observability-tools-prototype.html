记忆出错后，只做三件事

后台自动处理不打断；有已启用变更时，Host 汇总告知。你质疑时再展开依据、修改或撤销。

  1. 看看清本轮用了什么和原始来源。
  2. 改先看当前内容，再纠正、忘记或清除。
  3. 退批量撤销自动记忆更新：选中、一次确认。

本原型只验证宿主无关语义：这三步是否足够直观、安全，并且不把后台机制变成你的操作负担。卡片与点击仅供演示，不代表 Pi 或自研 TUI 的实际渲染；自由文本输入只覆盖固定演示语句，不代表生产意图分类器。
